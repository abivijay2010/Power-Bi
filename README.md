
# 🚴 AdventureWorks Power BI Project

This is a hands-on, project-based Power BI Desktop solution built for AdventureWorks, a global cycling equipment company. The goal is to track KPIs, analyze product trends, compare regional performance, and identify
high-value customers using raw CSV data.

## 📥 Download the Report

You can download and explore the full Power BI report here:

➡️ [Download 1st worksheet Power BI.pbix](./Reports/1st%20worksheet%20powerBI.pbix)


## 📊 Project Summary

- Cleaned and transformed raw sales, customer, and product data using Power Query
- Built a relational star and snowflake data model
- Created calculated columns and measures using DAX
- Designed an interactive dashboard with charts, filters, and drill-down capabilities

## 🔧 Tools Used

- Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- CSV Files (Sales, Returns, Customers, Products, Territories)

## 📁 Project Structure

- `Data/` – contains all source CSV files
- `Reports/` – includes the final `.pbix` report file
- `README.md` – this file

## 🧠 Key Concepts Covered

- ETL (Extract, Transform, Load) using Power Query
- Data modeling: normalization, relationships, cardinality
- DAX measures and calculated columns
- Visualizations: dashboards, filters, bookmarks
- Performance optimization

## 🚀 How to Use

1. Install [Power BI Desktop](https://powerbi.microsoft.com/downloads/)
2. Open the `.pbix` file in the `Reports/` folder
3. Refresh data if needed
4. Explore the dashboard and interact with visuals
